================================================================================
                    HUFFMAN FILE COMPRESSOR (C++17) - INSTRUCTIONS
================================================================================

1. COMPILATION
--------------------------------------------------------------------------------
Open a terminal in the root directory of this project:
    cd "file_path to txt-file-compressor"

To compile the application:
    make or make all {After running the first step and execution of make clean}

This will compile the C++17 source code and generate the executable at:
    ./bin/huffman

(Optional) To run the automated unit and integration tests:
    make test


2. HOW TO USE THE APPLICATION
--------------------------------------------------------------------------------
You can use the application in three main ways:

METHOD A: Compress a Single .txt File
    Pass the path of the .txt file directly as an argument:
        ./bin/huffman examples/sample.txt
    or with an absolute path:
        ./bin/huffman "/home/john-doe/Documents/my_notes.txt"

    What happens:
      - The file is compressed using Huffman coding.
      - The compressed output file (e.g., sample.txt.huf) is placed in the
        EXACT SAME DIRECTORY as the original uncompressed file.
      - Compression statistics (original size, compressed size, savings ratio,
        and elapsed time) are printed to the terminal.

METHOD B: Compress an Entire Directory Containing .txt Files
    Pass a folder path:
        ./bin/huffman examples
    or:
        ./bin/huffman "/path/to/my_folder"

    What happens:
      - The program scans the folder for all files ending in .txt.
      - It compresses each file individually.
      - Each resulting .huf file is placed in that folder right next to its
        respective original file.
      - A batch summary report is printed at the end.

    Tip (Recursive Subfolder Compression):
      Add the -r flag to also search subdirectories recursively:
        ./bin/huffman -r "/path/to/my_folder"

METHOD C: Interactive Mode (Prompt for Path)
    If you run the application with no arguments:
        ./bin/huffman

    The program will prompt you:
        Enter path to a .txt file or directory containing .txt files: 

    Type (or paste) the file or folder path and press Enter.


3. DECOMPRESSING A .HUF FILE
--------------------------------------------------------------------------------
To restore a compressed file back to its original uncompressed form:
    ./bin/huffman -d examples/sample.txt.huf

(The program also auto-detects .huf files, so you can simply run):
    ./bin/huffman examples/sample.txt.huf

What happens:
  - The program reads the serialized Huffman tree embedded in the file header.
  - It reconstructs the exact original file content.
  - The restored file is placed in the SAME directory. If the original .txt
    file still exists in that folder, it writes the output as
    <filename>_decompressed.txt to avoid overwriting your original.
  - You can verify the decompressed file matches the original byte-for-byte:
        diff -u examples/sample.txt examples/sample_decompressed.txt
    (No output from diff means both files are 100% identical).


4. COMMAND LINE OPTIONS SUMMARY
--------------------------------------------------------------------------------
  ./bin/huffman <path>            Compress file/dir, or decompress if .huf
  ./bin/huffman -c <path>         Explicitly compress file or directory
  ./bin/huffman -d <path.huf>     Decompress a .huf file
  ./bin/huffman -r <dir>          Recursively compress all .txt files in dir
  ./bin/huffman -h | --help       Show CLI help information


5. CLEANING UP
--------------------------------------------------------------------------------
To remove compiled object files and binaries:
    make clean
